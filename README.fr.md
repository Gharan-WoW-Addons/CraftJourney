# Craft Journey

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

*[English version](README.md)*

Un addon **World of Warcraft: Forever** qui suit vos commandes d'artisanat sur tous vos personnages.

> 🚧 **En cours de développement** — pas encore publié.

## Ce qu'il fait

Choisissez une recette, indiquez le nombre d'exemplaires, et Craft Journey affiche à l'écran les composants nécessaires, comme le suivi de quêtes : `possédé / nécessaire`, sacs et banque compris.

- **Toute la chaîne de composants** : pour 4 sacs, Craft Journey calcule les rouleaux d'étoffe *et* l'étoffe brute qu'il faut pour les fabriquer. Le calcul s'arrête au premier composant qu'aucun de vos personnages ne sait fabriquer.
- **Partagé entre vos personnages** : n'importe quel personnage peut suivre n'importe quelle commande. Créez une commande sur votre tailleur, suivez-la sur votre guerrier, et voyez combien d'étoffe il reste à farmer.
- **Totaux par personnage** : le suivi de chaque personnage additionne toutes les commandes qu'il suit.
