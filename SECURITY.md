# Security policy

*[Version française](SECURITY.fr.md)*

## Supported versions

Only the latest released version of Craft Journey receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a vulnerability.

Report it privately through GitHub: on the [Security tab](https://github.com/Gharan-WoW-Addons/CraftJourney/security) of the repository, click **Report a vulnerability** ([direct link](https://github.com/Gharan-WoW-Addons/CraftJourney/security/advisories/new)). Only the maintainers can read your report.

Please include:

- what an attacker could do, and in which conditions;
- the steps to reproduce it;
- the addon version and the game client version.

You will get an answer as soon as possible. Craft Journey is maintained on spare time: there is no guaranteed delay, but every report is read. Once the fix is released, the advisory is published and you are credited, unless you prefer not to be.
