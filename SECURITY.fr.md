# Politique de sécurité

*[English version](SECURITY.md)*

## Versions maintenues

Seule la dernière version publiée de Craft Journey reçoit les correctifs de sécurité.

## Signaler une faille

Merci de **ne pas** ouvrir d'issue publique pour une faille.

Signalez-la en privé via GitHub : dans l'[onglet Security](https://github.com/Gharan-WoW-Addons/CraftJourney/security) du dépôt, cliquez sur **Report a vulnerability** ([lien direct](https://github.com/Gharan-WoW-Addons/CraftJourney/security/advisories/new)). Seuls les mainteneurs peuvent lire votre signalement.

Merci d'indiquer :

- ce qu'un attaquant pourrait faire, et dans quelles conditions ;
- les étapes pour la reproduire ;
- la version de l'addon et celle du client du jeu.

Vous aurez une réponse dès que possible. Craft Journey est maintenu sur du temps libre : il n'y a pas de délai garanti, mais chaque signalement est lu. Une fois le correctif publié, l'avis de sécurité est rendu public et vous êtes crédité, sauf si vous préférez ne pas l'être.
